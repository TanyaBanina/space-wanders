# SpaceWanders

A 2D pixel-art platformer written in pure Java, without a game engine. Play as a small alien exploring five levels across different worlds, defeating every enemy to complete each level.

## Controls

| Key | Action |
|---|---|
| ← → | Move |
| W | Jump |
| E | Glide |
| R | Attack |
| F | Throw |
| Esc | Back to menu |

## How to run

Requires Java 8 or newer.

1. Clone the repository and open it in Java IDE.
2. Make sure the `Resources` folder is marked as a resources root.
3. Run the main class in the `Main` package.

## Built with

- Java (AWT / Swing), no external game libraries
